# Agentic Flow Practice Pack

This practice pack is a Programiz-style companion for two Agentic Flow subjects you completed:

1. Agentic Loop
2. Q&A Loop and an Agent Library

It follows a learn-then-digest structure that is especially useful for challenging topics like the tool-call loop, memory, and tool execution flow. The visual summary of the section explains that agents revolve around the LLM, instructions, tools, and memory; that the inner tool-call loop repeats until the LLM is done; and that the outer Q&A loop wraps the inner loop for interactive use. - `02-qna-loop-and-agent-library-practice.md`

## Suggested workflow

Use each chapter in this order:

1. Read the short recap.
2. Answer the quiz without running code first.
3. Do the guided practice tasks.
4. Do the debugging task.
5. Explain the concept in your own words.
6. Mark progress in `progress-tracker.md`.

This matches the teach -> quiz -> practice -> debug -> reflection flow that helps difficult concepts stick better. [cite:322]
